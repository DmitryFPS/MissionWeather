# MissionWeather Mobile (Capacitor)

Обёртка Android для PWA.

1. Соберите web: `npm run build -w @mission-weather/web` (static export при необходимости)
2. `npm install` в `apps/mobile`
3. `npm run sync`
4. `npm run android` — откроется Android Studio

APK подписывается в Android Studio (Build → Generate Signed Bundle).
